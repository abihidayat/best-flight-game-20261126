Island Run — Merpati Squadron: a 3D flight game. Fly the Merpati-7 prop plane over a procedural island, thread 10 glowing rings, watch your altitude, speed and heading. Keyboard + mouse, offline, static files, three.js. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Controls: arrows / WASD steer, Shift throttle up, Ctrl throttle down, C cockpit/chase camera, P pause, R restart, Space start. Fly through the glowing rings — all 10 finishes the course.
